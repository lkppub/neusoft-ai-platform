# 东软智慧商务AI助手平台 — 项目架构说明

## 技术栈

| 层 | 技术 | 版本 |
|------|------|------|
| 前端 | Vue 3 + Vite + Element Plus + Pinia + ECharts | Vue 3.5 |
| 后端 | FastAPI + SQLAlchemy + SQLite | Python 3.12 |
| AI | DeepSeek API (OpenAI 兼容 SDK) | openai 1.60+ |
| 向量库 | ChromaDB + sentence-transformers | Chroma 0.5+ |
| 智能体 | LangGraph (StateGraph 多节点编排) | LangGraph 0.2+ |
| 语音 | openai-whisper (STT) + pyttsx3/edge-tts (TTS) | |
| 部署 | Docker Compose (4 容器) + GitHub Actions CI/CD | |

## 系统架构

```
浏览器 (Vue3 SPA)
    │
    ├── /              → Nginx (:80) → 前端静态文件
    ├── /api/*         → Nginx (:80) → Backend (:8000)
    ├── /docs          → Nginx (:80) → Backend FastAPI Docs
    └── /health        → Nginx (:80) → Backend Health Check
                                │
                    ┌───────────┴───────────┐
                    │     FastAPI Backend    │
                    ├───────────────────────┤
                    │ AI Provider           │ → DeepSeek API
                    │ LangGraph Agent       │ → 多节点编排
                    │ Function Calling      │ → 查工单/搜知识库
                    │ RAG Pipeline          │ → ChromaDB 向量检索
                    │ Voice Service         │ → Whisper/pyttsx3
                    │ Redis Cache           │ → 响应缓存
                    │ SQLite Database       │ → 数据持久化
                    └───────────────────────┘
```

## AI 管道架构

### 工单处理管道（完整4节点）
```
分类 Agent → 检索 Agent → 回复 Agent ↔ 质检 Agent
   (1 LLM)     (向量库)     (1 LLM)       (1 LLM, 可循环)
```

### AI 对话管道（Function Calling 2工具）
```
用户消息 → LLM 决策
              ├── 调用 get_my_tickets → 数据库查询 → LLM 生成回复
              ├── 调用 search_knowledge → ChromaDB 检索 → LLM 生成回复
              └── 直接文本回复
```


## CI/CD 流水线

```
Git Push → GitHub Actions
  ├── Job 1: Backend Tests (pytest 4个用例)
  ├── Job 2: Frontend Build (npm run build)
  ├── Job 3: Docker Build (镜像构建 + 冒烟测试)
  └── Job 4: Push Registry (需配置 Secrets)
```
