# 东软智慧商务AI助手平台 — 产品功能说明

---

## 平台概述

东软智慧商务AI助手平台是一套面向企业的智能客户服务系统，融合大模型与智能体能力，为企业客户、客服人员、管理者提供智能化商务服务。

## 用户角色

| 角色 | 主要功能 |
|------|---------|
| 企业用户 | 提交工单、AI 智能对话、知识库查询、工单评价 |
| 客服人员 | 工单处理、AI 辅助回复、回复模板管理、FAQ 维护 |
| 管理员 | 用户管理、知识库管理、AI 配置、对话记录查看、分析报告 |
| 决策者 | 数据大屏、满意度趋势、AI 洞察 |

---

## 核心功能

### 1. AI 智能对话

- **自然语言交互**：输入问题，AI 自动理解意图并回复
- **Function Calling**：AI 可调用真实系统工具查询工单、搜索知识库
- **上下文记忆**：支持多轮对话，保持上下文连贯
- **SSE 流式输出**：回复逐字实时显示

### 2. 工单管理

- **工单创建**：填写主题、描述、优先级提交工单
- **AI 自动分类**：工单提交后 AI 自动分析并归类到 9 个固定类别
- **AI 建议回复**：客服可一键获取 AI 生成的专业回复
- **工单评价**：企业用户可对已解决工单评分（1-5 星）
- **回复模板**：预设常用回复，支持变量替换

### 3. 知识库

- **文档上传**：支持 PDF、Word、Excel、PPT、Markdown 等格式
- **自动处理**：上传后自动文本提取、分段、向量化索引
- **RAG 检索**：AI 基于知识库内容精准回答
- **FAQ 管理**：常见问题维护，自动同步到向量库

### 4. 语音交互

- **语音输入**：点击麦克风录音，自动转为文字
- **语音播报**：AI 回复一键朗读
- **中文优化**：使用微软慧慧中文语音引擎

### 5. 数据大屏

- **统计卡片**：咨询量、工单数、解决率、满意度
- **分类饼图**：问题分类分布可视化
- **满意度趋势**：折线图展示评分趋势
- **AI 洞察**：基于真实数据生成分析洞察

### 6. 多智能体协作

- **分类 Agent**：识别客户意图和问题类型
- **检索 Agent**：从知识库/数据库检索相关信息
- **回复 Agent**：生成专业回复
- **质检 Agent**：审查回复质量，不合格则退回修订

## 技术特性

| 特性 | 说明 |
|------|------|
| 大模型 | DeepSeek API，支持流式输出和 Function Calling |
| 向量检索 | ChromaDB + sentence-transformers，支持中文语义搜索 |
| 提示词工程 | 按场景管理 PromptTemplate，支持变量替换 |
| 容器化 | Docker Compose 一键部署，4 个容器协同工作 |
| CI/CD | GitHub Actions 自动测试、构建、镜像打包 |
