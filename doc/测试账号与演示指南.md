## 演示流程

### 1. 企业用户提交工单

1. 用 `enterprise / 123456` 登录
2. 进入「工单」页面 → 点击「创建工单」
3. 填写主题"系统登录失败"、描述"输入密码后点击登录无反应"
4. 提交 → AI 自动分类为"账号问题"

### 2. AI 智能对话

1. 进入「AI 对话」页面
2. 输入"帮我查工单" → AI 调用 get_my_tickets 工具，返回真实工单
3. 输入"忘记密码怎么办" → AI 搜索知识库，返回 FAQ 答案
4. 输入"今天天气" → AI 诚实告知无法回答

### 3. 客服处理工单

1. 用 `cs_staff / 123456` 登录
2. 进入「工单」页面 → 点击刚才创建的工单
3. 点击「🤖 分类」→ AI 确认分类
4. 点击「💡 建议回复」→ AI 生成专业回复
5. 编辑/确认回复 → 点击「发送」
6. 点击「✅ 解决」→ 工单关闭

### 4. 企业用户评价

1. 切换回 `enterprise` 账号
2. 打开已解决的工单
3. 右侧出现「服务评价」卡片
4. 点击 ★★★★ 评分，填写留言 → 提交

### 5. 数据大屏

1. 用 `admin / 123456` 登录
2. 进入「数据大屏」
3. 查看实时统计卡片、分类饼图、满意度趋势、AI 洞察

### 6. 语音功能（需 Windows 环境）

1. 工单详情页 → 回复框旁的 🎤 按钮 → 录音 → 自动转文字
2. AI 建议回复 → 🔊 播放按钮 → 语音朗读

## Function Calling 测试用例

| 输入 | 预期 AI 行为 |
|------|-------------|
| "帮我查工单" | 调用 get_my_tickets → 返回真实工单列表 |
| "我的工单状态" | 同上 |
| "忘记密码怎么办" | 调用 search_knowledge → 返回 FAQ 答案 |
| "工单优先级怎么定义的" | 调用 search_knowledge → 返回工单文档内容 |
| "今天天气怎么样" | 不调工具 → 诚实告知无法回答 |
| "帮我删除工单" | 不调工具 → 告知只能查工单，无法执行操作 |
